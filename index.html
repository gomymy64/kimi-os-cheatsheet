Шаги

Семь шагов по порядку. Промпты копируются кнопкой.

01

Ставим Kimi Code

Вся работа дальше идёт в этом приложении. API-ключ для него не нужен - хватает аккаунта Kimi.

  • Открой kimi.ai/code и скачай Kimi Code под свою систему
  • Установи и войди своим аккаунтом Kimi
  • Создай на компьютере пустую папку под проект
  • Открой новую сессию и выбери эту папку
  • В выборе модели поставь K3.1 Pro
Есть ещё K3.1 Pro Highspeed - та же модель, только в два-три раза быстрее. Она открывается на тарифе Pro и выше.
02

Нейронка пишет техзадание

Огромный промпт сам не пиши. Попроси нейронку написать его за тебя - она лучше знает, как объяснить задачу самой себе.

  • Вставь промпт в новую сессию Kimi Code и отправь
  • Получишь подробное техзадание: загрузка, вход, окна, меню «Пуск», приложения и ИИ-ассистент
Промпт 1 - техзадание на систему
Напиши мне промпт, который я вставлю в Kimi Code, чтобы он собрал операционную систему в стиле Windows 11. Назовём её Mastodon OS. Она должна работать прямо в браузере и открываться двойным кликом по index.html, без установки и без сервера. Внутри - свой ИИ-ассистент Мастодонт: чат, который общается дерзко и уверенно, а API-ключ для него вводится в настройках системы.
03

Kimi Code собирает систему

Отдаём техзадание обратно в Kimi Code. Он сам разбивает задачу на план, создаёт файлы один за другим и не дёргает тебя вопросами.

  • Скопируй техзадание из ответа целиком
  • Вставь его в Kimi Code в той же папке и отправь
  • Дождись, пока он пройдёт свой план до конца
  • Открой index.html из папки двойным кликом - это твоя система
Модель
K3.1 Pro с максимальной глубиной размышлений - самый умный режим. Highspeed - быстрее
04

Доводим систему итерациями

Первая версия обычно выглядит бедно: без картинок, обоев и иконок. Самые крутые результаты получаются в следующих заходах.

  • Напиши в ту же сессию, что поправить: обои, иконки, плавность
  • Попроси промпты для картинок, сгенерь их и кинь файлы обратно в чат
  • Проверь, что работает: окна двигаются, папки создаются, в проводнике можно делать текстовые документы
05

Подключаем ИИ-ассистента

Ассистенту внутри системы нужен свой ключ. Берём его на платформе Kimi API.

  • Открой платформу Kimi API и создай ключ в разделе API Keys
  • Скопируй ключ и вставь его в настройки ассистента в своей системе
  • Сохрани
Base URL
https://api.moonshot.ai/v1
Модель
kimi-k3.1-pro
06

Командуем системой из чата

Ассистент не просто болтает - он сам управляет системой. Пиши ему по одной команде.

Команды ассистенту
Поставь светлую тему и разложи окна
Верни тёмную тему
Создай 10 папок
Удали папки
Создай 5 блокнотов и в каждый сокращённую версию каждого произведения Шекспира
Открой блокнот и калькулятор. Поставь светлую тему и разложи окна
Не нравится характер ассистента - попроси Kimi Code поменять ему стиль общения, например сделать дерзким рок-н-ролльщиком.
07

Встраиваем КС и Доту

Вместо Сапёра и Косынки - набор истинного мастодонта. Возвращаемся в ту же сессию Kimi Code.

Промпт 2 - игры в систему
Добавь в Mastodon OS две встроенные игры, как Сапёр в Windows: 3D-шутер в духе Counter-Strike с картой по мотивам Dust 2 и арену в духе Доты. Обе должны появиться в меню "Пуск" как обычные приложения.
  • Попроси найти готовые 3D-модели или сделать их самому - так игры выглядят живее
  • Запусти игру из меню «Пуск», разверни на весь экран клавишей F11 и поставь графику на ультра
